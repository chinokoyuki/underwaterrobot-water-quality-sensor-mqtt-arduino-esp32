## 1. 系统概述

本系统是一套基于 Arduino Nano ESP32 的多参数水质监测系统，能够实时采集水质数据并通过 WiFi 上报至华为云 IoT 平台。

### 1.1 监测参数

| 参数 | 传感器 | 量程 | 精度 |
|---|---|---|---|
| pH 值 | pH 传感器模块 | 0 ~ 14 | ±0.1 |
| TDS (溶解性固体总量) | TDS 传感器模块 | 0 ~ 2000 ppm | ±10% |
| 浊度 | 浊度传感器模块 | 0 ~ 4095 (ADC原始值) | — |
| 氨氮 | 氨氮传感器模块 | 0 ~ 50 mg/L | ±5% |
| 水温 | DS18B20 | -55 ~ 125 ℃ | ±0.5 ℃ |
| 水深 | MS5837 压力传感器 | 0 ~ 30 m | ±0.2% FS |

### 1.2 核心功能

- **多传感器实时采集**：6路传感器同步采集水质数据
- **自动水质判断**：根据阈值自动判断水质是否正常
- **超标报警**：水质超标时自动触发蜂鸣器/LED报警
- **WiFi 联网**：自动连接指定WiFi热点
- **MQTT 数据上报**：数据实时上传华为云 IoT 平台
- **校准参数掉电保存**：校准系数存储在 Flash 中，断电不丢失

## 5. 传感器详细说明

### 5.1 pH 传感器

- **接口**：模拟输入 (A0)
- **工作电压**：3.3V
- **测量原理**：通过ADC读取传感器电压，根据公式计算 pH 值
- **计算公式**：`pH = 7 + (3.3/2 - 电压) × (-5/3) + 偏移量`
- **采样方式**：10次平均去噪
- **输出范围**：0 ~ 14

### 5.2 TDS 传感器

- **接口**：模拟输入 (A1)
- **工作电压**：3.3V
- **测量原理**：通过ADC读取电压，转换为 TDS 值（ppm）
- **计算公式**：`TDS = (电压/3.3) × 133.42 × 温度补偿系数`
- **温度补偿**：`补偿系数 = 1 + 0.02 × (水温 - 25)`
- **输出范围**：0 ~ 2000 ppm

### 5.3 浊度传感器

- **接口**：模拟输入 (A2)
- **输出方式**：直接返回 ADC 原始值（0 ~ 4095）
- **说明**：数值越大，表示水体越浑浊

### 5.4 氨氮传感器

- **接口**：模拟输入 (A3)
- **工作电压**：3.3V
- **计算公式**：`氨氮 = (电压/3.3) × 50 × 校准系数`
- **输出范围**：0 ~ 50 mg/L

### 5.5 DS18B20 水温传感器

- **接口**：单总线 (A4)
- **工作电压**：3.3V（寄生供电或独立供电）
- **精度**：±0.5 ℃（-10 ~ 85 ℃ 范围内）
- **分辨率**：9 ~ 12 位可编程（默认12位，0.0625 ℃）
- **注意事项**：DQ 数据线必须接 4.7KΩ 上拉电阻

### 5.6 MS5837 深度传感器 ⭐新增

- **接口**：I2C (GPIO8=SCL, GPIO9=SDA)
- **工作电压**：1.5 ~ 3.6V（接3.3V）
- **I2C 地址**：0x76（标准）/ 0x77（备用）
- **压力量程**：0 ~ 30 bar
- **深度量程**：0 ~ 300 m（淡水）/ 0 ~ 290 m（海水）
- **精度**：±0.2% FS
- **分辨率**：24位 ADC，OSR最高4096
- **特性**：
  - 内置温度传感器，二阶温度补偿
  - 支持淡水/海水密度切换
  - 自动读取PROM校准系数

## 6. 系统操作指南

### 6.1 首次启动

1. 按接线图连接所有传感器
2. USB-C 连接电脑
3. 烧录固件（见 3.3 节）
4. 打开串口监视器（115200 波特率）
5. 观察启动日志：

```
水质监测系统初始化完成
[DepthSensor] MS5837 校准系数:
  C1 = xxxx
  C2 = xxxx
  ...
[WaterSensor] 深度传感器初始化成功
pH值    TDS值(ppm)       浊度(ADC)       氨氮(mg/L)      水温(℃) 深度(m) 状态
7.02    234.5            1024            3.21            25.3    0.15    正常
```

### 6.2 正常运行

系统启动后自动进入循环采集模式：

1. 使能传感器供电（GPIO2 = HIGH）
2. 等待 500ms 传感器稳定
3. 依次读取 6 路传感器数据
4. 判断水质是否正常
5. 超标则触发报警（GPIO3 = HIGH）
6. 串口输出数据
7. 通过 MQTT 上报华为云
8. 等待 2000ms 后重复

### 6.3 水质判断阈值

| 参数 | 正常范围 | 超标判定 |
|---|---|---|
| pH 值 | 6.0 ~ 8.0 | < 6.0 或 > 8.0 |
| TDS | 0 ~ 500 ppm | > 500 ppm |
| 氨氮 | 0 ~ 10 mg/L | > 10 mg/L |
| 深度 | 0 ~ 10 m | > 10 m |

### 6.4 串口数据格式

```
pH值\tTDS值(ppm)\t浊度(ADC)\t氨氮(mg/L)\t水温(℃)\t深度(m)\t状态
```

示例输出：
```
7.15    189.3           856             2.45            24.8    0.32    正常
5.80    612.4           2048            15.67           26.1    0.28    超标报警
```

## 7. MQTT 云端配置

### 7.1 华为云 IoT 参数

在 `main.cpp` 中修改以下参数以适配你的华为云实例：

```cpp
/* 华为云 IoTDA 设备配置 */
#define DEVICE_ID         "你的设备ID"
#define DEVICE_SECRET     "你的设备密钥"

/* WiFi 配置 */
#define WIFI_SSID         "你的WiFi名称"
#define WIFI_PASSWD       "你的WiFi密码"

/* 华为云 MQTT 连接参数 */
#define MQTT_SERVER       "你的华为云MQTT地址"
#define MQTT_PORT         1883
#define MQTT_USERNAME     "你的MQTT用户名（通常与DEVICE_ID相同）"
#define CLIENT_ID         "你的客户端ID"
#define MQTT_PASSWD       "你的MQTT密码"
```

> 💡 MQTT 密码需要通过华为云提供的生成工具或算法计算，详见 `doc/MQTT华为云对接手册.md`。

### 7.2 数据上报格式

设备使用华为云 IoTDA 标准属性上报格式，将所有传感器数据封装为 JSON 上报。

#### 上报 Topic

```
$oc/devices/{device_id}/sys/properties/report
```

#### 上报 Payload

```json
{
  "services": [{
    "service_id": "water_quality",
    "properties": {
      "pH": 7.15,
      "TDS": 189.3,
      "turbidity": 856,
      "ammoniaNitrogen": 2.45,
      "waterTemp": 24.8,
      "depth": 0.32,
      "depthPressure": 1013.5,
      "depthSensorTemp": 24.5,
      "waterQualityNormal": true,
      "depthSensorOnline": true
    }
  }]
}
```

#### 属性字段说明

| 属性名 | 数据类型 | 单位 | 说明 |
|---|---|---|---|
| `pH` | float | — | pH 值（0 ~ 14） |
| `TDS` | float | ppm | 溶解性固体总量（0 ~ 2000） |
| `turbidity` | int | — | 浊度 ADC 原始值（0 ~ 4095） |
| `ammoniaNitrogen` | float | mg/L | 氨氮浓度（0 ~ 50） |
| `waterTemp` | float | ℃ | DS18B20 水温（0 ~ 100） |
| `depth` | float | m | MS5837 水深（0 ~ 30） |
| `depthPressure` | float | mbar | 深度传感器压力值 |
| `depthSensorTemp` | float | ℃ | 深度传感器内部温度 |
| `waterQualityNormal` | boolean | — | 水质是否正常 |
| `depthSensorOnline` | boolean | — | 深度传感器是否在线 |

#### 华为云物模型配置

在华为云 IoTDA 控制台的"物模型"中，需创建一个名为 `water_quality` 的服务，并添加上述 10 个属性。每个属性的"数据类型"须与上表一致（float 对应 decimal，int 对应 int，boolean 对应 boolean）。

> 📖 详细的物模型创建步骤和参数配置请参考 `doc/MQTT华为云对接手册.md`。

### 7.3 MQTT 上报周期

| 操作 | 间隔 | 说明 |
|---|---|---|
| 传感器采集 | 2 秒 | 读取所有传感器数据并串口输出 |
| 数据上报 | 5 秒 | 通过 MQTT 上报到华为云 |
| 连接检查 | 持续 | 每次 loop 均检查 MQTT 连接 |

### 7.4 MQTT 连接流程

```
设备上电
  ↓

  ↓
MQTT 连接华为云 IoTDA
  ↓
┌──────────────────────────┐
│  采集传感器数据 (2s)       │ ←── 持续循环
│  串口输出数据              │
│  MQTT 上报数据 (5s)       │
│  处理 MQTT 下发消息        │
└──────────────────────────┘
```

设备已注册 MQTT 消息回调函数，可接收华为云平台下发的属性设置和命令。当前版本仅打印接收到的消息，未实现具体的命令执行逻辑，后续可按需扩展。

## 8. 校准方法

### 8.1 pH 传感器校准

1. 准备 pH 4.0 和 pH 7.0 标准缓冲液
2. 将 pH 传感器分别浸入两种缓冲液
3. 读取串口输出的电压值
4. 调整 `WaterQualitySensor.h` 中的参数：

```cpp
#define PH_OFFSET 0.0f      // pH校准偏移量
#define PH_SLOPE (-5.0f/3.0f) // pH传感器斜率
```

5. 调用 `saveCalibrationParams()` 保存到 Flash

### 8.2 TDS 传感器校准

1. 准备已知 TDS 值的标准液
2. 读取电压值，计算校准系数
3. 修改代码中的 `_tdsCoefficient`（默认 133.42）

### 8.3 氨氮传感器校准

1. 准备已知浓度的氨氮标准液
2. 读取电压值，计算校准系数
3. 修改代码中的 `_ammoniaCoefficient`（默认 1.0）

### 8.4 深度传感器校准

MS5837 出厂时已校准（PROM 中存储校准系数），通常无需手动校准。

如需校准：
- 调用 `setFluidDensity()` 设置正确的流体密度
- 淡水默认：997 kg/m³
- 海水：1025 kg/m³

## 9. 常见问题与排障

### Q1: 编译报错 "Wire.h: No such file or directory"

**原因**：Wire 库未正确加载。
**解决**：检查 `platformio.ini` 中 `framework = arduino` 是否正确，重新编译。

### Q2: DS18B20 温度显示 -1.0 或 -127.0

**原因**：传感器未连接或上拉电阻缺失。
**解决**：
1. 检查 DS18B20 接线（VDD、DQ、GND）
2. 确认 DQ 引脚已接 4.7KΩ 上拉电阻到 3.3V
3. 确认 DS18B20 未损坏

### Q3: 深度传感器初始化失败

**原因**：I2C 通信异常。
**解决**：
1. 检查 MS5837 接线（SCL、SDA、VCC、GND）
2. 确认 I2C 总线已接上拉电阻（SCL 和 SDA 各一个 4.7KΩ）
3. 确认 MS5837 供电电压为 3.3V（不可接 5V）
4. 运行 I2C 扫描程序检查设备地址：
   ```cpp
   #include <Wire.h>
   void setup() {
     Serial.begin(115200);
     Wire.begin(9, 8);
     for (byte addr = 1; addr < 127; addr++) {
       Wire.beginTransmission(addr);
       if (Wire.endTransmission() == 0) {
         Serial.print("Found: 0x");
         Serial.println(addr, HEX);
       }
     }
   }
   void loop() {}
   ```

### Q4: WiFi 连接失败

**原因**：WiFi 名称或密码错误，信号弱。
**解决**：
1. 确认 `WIFI_SSID` 和 `WIFI_PASSWD` 正确
2. 确保 ESP32 距离路由器较近
3. 不支持 5GHz WiFi，请使用 2.4GHz

### Q5: MQTT 上报失败

**原因**：连接参数错误或网络问题。
**解决**：
1. 检查 `MQTT_SERVER`、`CLIENT_ID`、`MQTT_PASSWD` 是否正确
2. 确保华为云 IoT 实例正常运行
3. 检查设备是否已在线（华为云控制台查看）

### Q6: pH 值读数偏差大

**原因**：传感器需要校准。
**解决**：参考第 8 节校准方法，使用标准缓冲液校准。

### Q7: 深度值一直为 0 或负值

**原因**：MS5837 未浸入水中时，测量的是大气压。
**解决**：这是正常现象，传感器未入水时深度应为 0 或极小值。浸入水中后深度值会上升。

### Q8: 报警持续触发

**原因**：某项水质参数超标。
**解决**：
1. 查看串口输出确认哪项参数超标
2. 检查传感器读数是否合理
3. 必要时调整 `WaterQualitySensor.h` 中的阈值

| A1 | TDS 传感器 | 输入 | 模拟输入，10次平均 |

| A3 | 氨氮传感器 | 输入 | 模拟输入，10次平均 |
